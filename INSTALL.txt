GUARDIAN OPERATIONS — CLEAN WEBSITE SOURCE

1. Make a fresh backup of the current live Guardian website and its data/configuration before changing anything.
2. Keep RECOVERY_BACKUP separate; do not copy its JSON over the live data folder automatically.
3. Copy the source files into your existing guardian-web Git repository. Do not replace the existing data folder unless you have compared and merged it deliberately.
4. In GitHub Desktop, inspect every changed file. Commit with a clear message such as: Granular Settings permissions redesign.
5. Push origin and wait for Render to deploy the connected main branch.
6. Test login, vehicle list, settings navigation, roles, training, map, dispatch, FiveM status, and backup/export before giving any staff new access.

Roles & Permissions update details are in ROLE_PERMISSIONS_UPDATE.txt.
This source ZIP has not been deployed to Render and has not been tested against your live production data.
