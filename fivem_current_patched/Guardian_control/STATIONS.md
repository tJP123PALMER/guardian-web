# Callsign / Station configuration

Edit `config.lua`:

```lua
Config.CallSignStations = {
    ["K06P1"] = "Station 6",
    ["K06P2"] = "Station 6",
    ["N14P1"] = "Station 14",
    ["N14P2"] = "Station 14",
}
```

The mapping is shown in Control's Appliance Board and Stations tab.
Changes take effect after restarting the Guardian_control resource.
